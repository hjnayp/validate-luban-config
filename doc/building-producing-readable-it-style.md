# 建筑配置校验可读性调整：恢复单规则单 it

## 背景
规则表驱动能减少样板代码，但在当前团队协作场景中，逐条阅读与快速定位更重要。

## 调整内容
- 保留已抽离的纯函数（错误收集与格式化）；
- 取消 `validation_rules` 规则表与通用循环执行；
- 恢复为每条规则独立一个 `it` 用例；
- 保留新增的“道具产物存在性”校验。

## 效果
- 阅读路径更直观：看到 `it` 即可了解业务规则；
- 维护成本可控：逻辑复用仍由纯函数承担；
- 失败定位更快：测试名称与规则一一对应。
